# TLDR - MercadoMax

## Flujo corto para Windows

1. Abre Docker Desktop.
2. Abre este repo en VS Code.
3. Usa `Dev Containers: Reopen in Container`.
4. En la terminal del contenedor corre:

```bash
connection-info
check
```

5. Lee:
   - `docs/company-context.md`
   - `docs/scope-and-focus.md`
   - `docs/main-questions.md`
6. Explora:
   - `schema/initial_schema.sql`
   - `schema/seed.sql`
   - `data/sample/`
7. Empieza a tomar decisiones propias.

## Idea central

Este repo no resuelve MercadoMax por ti.

Te da un arranque reproducible para pensar pedidos, pagos, inventario y devoluciones con un alcance pequeño y defendible.
