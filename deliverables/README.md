# Deliverables

Este starter kit no te pide una entrega final inmediata, pero sí prepara el terreno para lo que debería venir después.

Más adelante deberías poder producir algo como:

- problema resumido
- alcance elegido
- modelo inicial explicado
- reglas principales
- consultas relevantes
- una decisión técnica defendible
- una reflexión breve sobre límites o riesgos

Usa `REPORT.md` como punto de partida para ordenar ideas.
