# MercadoMax - Business Rules

Reglas iniciales sugeridas:

1. Un pedido debe pertenecer a un solo cliente.
2. Un pedido necesita al menos una partida para tener sentido operativo.
3. Un pago confirmado no debería existir para un pedido cancelado sin justificación.
4. El inventario disponible no debería quedar negativo por operación normal.
5. Una devolución debe referirse a un pedido existente.
6. No todos los pedidos pagados están completados inmediatamente.
7. Un producto puede existir sin ventas todavía.
8. Una devolución puede ser parcial, no necesariamente por toda la orden.
