# MercadoMax - Contexto de empresa

MercadoMax es una tienda ficticia que vende productos de consumo y necesita operar pedidos de manera confiable.

Hoy el equipo tiene visibilidad parcial: sabe que hay pedidos, pagos, inventario y devoluciones, pero no siempre puede responder con claridad preguntas básicas como:

- qué pedidos siguen pendientes
- qué productos realmente están generando ingresos
- qué devoluciones están afectando ventas netas
- qué productos están cerca de quedarse sin inventario

La meta del proyecto no es construir un ERP completo. La meta es diseñar una base útil, coherente y defendible para un recorte razonable del problema.
