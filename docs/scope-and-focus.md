# MercadoMax - Scope and Focus

## Foco sugerido

Este starter kit sugiere concentrarse en:

- pedidos
- pagos
- inventario
- devoluciones simples

## Sí entra

- registrar clientes básicos
- registrar productos
- registrar pedidos y sus partidas
- registrar pagos principales
- estimar inventario disponible por producto
- observar devoluciones con motivo breve

## No entra por ahora

- logística completa de envíos
- promociones avanzadas
- múltiples almacenes complejos
- contabilidad formal
- integración con app o portal web
- analítica histórica completa

## Intención pedagógica

Si el alcance se mantiene pequeño, será más fácil:

- modelar bien entidades y relaciones
- justificar reglas
- detectar inconsistencias
- defender consultas útiles
