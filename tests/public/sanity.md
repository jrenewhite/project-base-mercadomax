# Public Sanity Check

El sanity check público de este starter kit solo verifica que:

- PostgreSQL responde
- el schema cargó
- existen varias tablas públicas
- se genera `actual/sanity-check.txt`

No evalúa si el modelo es suficiente, elegante o final.

La intención es comprobar que el entorno sí quedó listo para empezar el proyecto.
